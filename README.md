# GANYAN AYCISI

Streamlit tabanlı responsive at yarışı analiz arayüzü.

## Yerelde çalıştırma
```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub ve Streamlit Community Cloud
1. Bu klasörün içindeki dosyaları GitHub deposuna yükleyin.
2. Streamlit Community Cloud'da depoyu seçin.
3. Main file path: `app.py`

## Veri durumu
İlk sürümde görsellerdeki örnek veriler kullanılır. Henüz TJK, hava, AGF,
sabit oran, muhtemel ganyan, galop ve yarış sonuçları için canlı bağlantı yoktur.
Bu bağlantılar daha sonra `fetch.py` içindeki fonksiyonlara eklenecektir.
